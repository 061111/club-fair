# 社团百宝箱 · 百团大战新生选社 H5

社团文化节 / 百团大战用的新生选社工具：兴趣标签开屏 → 按模块匹配推荐社团 → 可交互场馆平面图（缩放拖动 / 搜索定位 / 摊位状态）。

## 功能

- **两步开屏**：四大模块（公益 / 人文 / 科技 / 体育）选一 → 模块内勾选兴趣标签
- **为你推荐**：标签匹配算法排序，显示匹配度、前三名徽标、摊位号
- **场馆平面图**：舞台 / 观众区 / 门头 + 摊位队列，支持双指缩放、拖动、按钮缩放
- **搜索定位**：搜社团名 / 标签 / 摊位号，地图自动放大聚焦并高亮闪烁
- **摊位状态**：摆摊中 / 已收摊（收摊格子灰化划线），管理员改数据即时生效
- **玩法说明**：活动介绍弹窗，内容可配置

## 使用

纯原生 HTML/CSS/JS，零依赖、零构建：直接双击 `index.html` 或部署到任意静态托管。

## 数据维护（活动筹备同学看这里）

所有业务数据集中在 **`js/data.js`**，文件头部有完整维护指南：

- `CONFIG`：活动名称 / 时间 / 地点 / 玩法说明文字
- `MODULES` / `TAGS`：四大模块与兴趣标签
- `CLUBS`：社团列表（摊位号 `booth`、状态 `status`、照片 `photos`、活动介绍 `activities`）
- `MAP_LAYOUT`：场馆平面图布局（`runs` 摊位队列的起止编号与坐标）

社团报名结束后只需改这一个文件，页面自动更新。
